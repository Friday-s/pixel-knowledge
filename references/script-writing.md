# 文稿怎么写（episode.json）

四集实测下来的结构：35–41 句、合计 575–650 个汉字（含标点约 670–750 字），念完 2:20–2:30（edge-tts 云希含句间停顿约 4.9 汉字/秒；648 字那集 2:31，574 字那集 2:22）。每句 12–28 个字，一句只说一件事，因为一句对应一个画面。

## 字段

```json
{
 "title": "金钱心理学",                       // 片名（文件名、标题卡用）
 "book": {"name": "金钱心理学", "author": "摩根·豪泽尔", "kind": "传说 · 财商"},   // 技能书卡上的字
 "channel": "读书搭子",                        // 终章「邀请你组队」显示的名字
 "voice": "zh-CN-YunxiNeural", "rate": "+0%",  // 音色/语速（见下）
 "chapters": ["财富看不见", "知道够了", "别下牌桌", "隐藏关"],   // 顶部章节栏；前三项=三关标题（4–6 字），最后一项=隐藏关或终章
 "tail": 2.6,                                  // 最后一句念完后留几秒（组队按钮按下去）
 "lines": [["文本，[关键词]用方括号。", 句前停顿秒], …]
}
```

## 骨架（照这个顺序写，锚句的句式别改）

| 段 | 句数 | 写什么 | 锚句（引擎靠它找位置） |
|---|---|---|---|
| 钩子 | 4–5 | 一个反常识的对比、一个人人中过招的日常场景、或书里最抓人的故事，结尾抛个问题或反转 | — |
| 技能书 | 1 | 亮书名 | `这本书叫《[书名]》。` 必须含《》 |
| 作者 | 1 | 作者是谁 + 全书一句话主张（能做成金句卡） | 紧跟书名句 |
| 预告 | 1 | `今天带你闯[三关]。` / `今天学[三招]，帮你……` | 第一关的前一句 |
| 第一关 | 5–7 | 关卡句 + 4–6 句展开：概念 → 书里的例子 → 换个角度 → 一句收束 | `第一关：……` 开头 |
| 第二关 | 5–7 | 同上 | `第二关：……` 开头 |
| 第三关 | 5–7 | 同上 | `第三关：……` 开头 |
| 隐藏关 | 3–5 | 升华：三关之上的那个答案（自由/幸福/问自己……） | 含 `隐藏关`，如 `三关打完，还有一个[隐藏关]。` |
| 回扣 | 2–3 | 回到开头那个场景/人物，用学到的东西重新看一遍 | 含 `回到开头` |
| 道具 | 1 | 把全片收成一个道具名 | 含 `道具`，如 `现在你手里多了一件道具：[够了]。` |
| 提问 | 1 | 一个和观众自己有关、一句话能答的问题 | 含 `[评论区]` |
| 关注 | 1 | 固定收尾 | 最后一句：`关注我，下一本书，[我们一起读]。` |

章节栏会在「第一关」前一句（预告句）的关键词时刻滑出来。

## 方括号关键词

- 每句最多一个 `[]`（个别句子两个也行，引擎只用第一个），包 2–6 个字，是这句的「画面发生点」：字幕里变金色，K(i) 时刻 = 这几个字念出来的那一刻，画面上该发生的事就挂在这里。
- 放在句子后半段效果最好（先铺垫再点题），比如 `可他身边全是[亿万富翁]，他觉得自己还远远不够。`
- 关键词要具体可画：`[破产]`、`[八百万美元]`、`[背包]`、`[终点线]` 好画；`[很重要]`、`[其实]` 画不出来。

## 停顿（每句第二个数字）

- 开场第一句 1.2；关卡句、隐藏关句 1.3（给关卡卡弹出留时间）；书名句 0.9；回扣句 0.6；提问句 0.6。
- 同一段里紧接着的句子 0.25–0.4；段内换话题 0.5。

## 语气与禁忌

- 口语、短句、第二人称（「你」），像在跟朋友讲；少用「首先其次」「综上所述」。
- 游戏词汇是包装不是内容：每关仍然要讲清一个真观点 + 一个具体例子。
- **事实必须准确**：作者名、书里的故事、数字、引语都要对。记不准就换成概述（「书里说……」后面跟意思，不加引号不编原话）；不确定的数字不写。
- 涉及真实人物（巴菲特、某 CEO）只陈述公开事实，不做道德评判以外的发挥；画面里不画成真人的样子。
- 不在文稿里出现网址、二维码、具体商品推广。

## 多音字（听不到音频，只能事先避开）

edge-tts 遇到多音字会按常见读法念，常错的：系（xì/jì）、当（dāng/dàng）、得（dé/de/děi）、还（hái/huán）、行（xíng/háng）、长（cháng/zhǎng）、重（zhòng/chóng）、为（wéi/wèi）、了（le/liǎo）、着（zhe/zháo）、调（diào/tiáo）、差（chà/chā）、种（zhǒng/zhòng）、数（shù/shǔ）、处（chù/chǔ）、好（hǎo/hào）。写完扫一遍，有歧义就换说法：「系好鞋带」→「穿上跑鞋」，「当自己是」→「觉得自己是」，「得先」→「要先」，「行长」→「银行老板」。

## 音色

`edge-tts --list-voices | grep zh-CN` 可查全部。常用：`zh-CN-YunxiNeural`（年轻男声，三集都用它）、`zh-CN-XiaoxiaoNeural`（女声，温和）、`zh-CN-YunjianNeural`（男声，有力）、`zh-CN-XiaoyiNeural`（女声，活泼）。语速 `"rate": "+5%"` 之类。改了音色/语速重跑 `pk voice`，画面自动跟（时间全挂在句子上）。

## 三个范例的世界观（换书时参考这种「一个比喻贯穿全片」的思路）

- 《被讨厌的勇气》：人生是背不完的「任务卷轴」；三关 = 过去不算数（读档重来）/ 这是谁的任务（课题分离，把卷轴还回去）/ 被讨厌也没关系（十个人里一个讨厌你）；终章 = 贡献感。
- 《学会提问》：刷到的信息都是「未鉴定道具」，提问是「鉴定术」；三关 = 拆开（结论/理由，论证桥）/ 证据够硬吗（分量、替代原因）/ 话术陷阱（地牢里的谬误）；隐藏关 = 拿同样的问题问自己。
- 《金钱心理学》：「装备」穿给别人看，「背包」里的金币才是自己的；三关 = 财富看不见 / 知道够了（终点线别挪）/ 别下牌桌（巴菲特曲线）；隐藏关 = 自由。
