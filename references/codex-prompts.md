# Codex 生图提示词 + 像素化参数（三集实测）

## 怎么调

```bash
pk gen <目录> <名字> "<提示词>" [参考图…]        # 单张
pk gen <目录> --batch gen/batch.json             # 多张并行（默认 4 路），放后台
```
batch.json：
```json
[
 {"name": "x_office", "prompt": "{BG} 场景：……", "refs": ["<SKILL>/library/refs/scene_town.png"]},
 {"name": "x_people", "prompt": "{STYLE} {GREEN} 【一致性】画风、头身比、像素块大小、描边必须和附图里的角色完全一致（同一款游戏）。不要画成任何真实名人的样子。 两个新角色的动作表：……", "refs": ["<SKILL>/library/refs/hero.png"]},
 {"name": "x_props", "prompt": "16-bit 像素画游戏道具表，大像素块、1 像素深色描边、无抗锯齿、和附图同一款游戏的画风：横排 5 个独立道具，彼此留出明显空隙互不接触、大小相近：① … ② … {MAGENTA}", "refs": ["<SKILL>/library/refs/props.png"]}
]
```
（`<SKILL>` 换成实际的 skill 目录绝对路径；参考图路径也可以写相对项目目录的 `gen/xxx.png`。）

占位符会被替换成 `prompts/` 里的固定段落：
- `{STYLE}`：角色像素画风（约 48 像素高、2×2 点眼睛、最多两级明暗、≤16 色、绿幕）。**所有角色表开头都要有。**
- `{BG}`：场景底板（320×180 小图整数倍放大、正面平视横版、不要人物动物文字、招牌空白、16:9）。
- `{GREEN}` / `{MAGENTA}`：纯色抠像背景硬性要求。角色用绿幕；道具、或角色本身有绿色（植物、绿衣服）用洋红幕。

每张约 1–2 分钟（4 张并行约 1.5 分钟）。已存在同名 png 会跳过，想重画先删 `gen/<名字>.png`。失败看 `gen/<名字>.log`。

## 写法要点

- **一致性靠参考图**：新角色传 `library/refs/hero.png`（主角）或 `people.png`；新场景传 `scene_town.png` / `scene_city.png` / `scene_dungeon.png` 中最接近的一张；新道具传 `props.png`。提示词里写「和附图同一款游戏的画风」。
- **场景**：写清时段、色调、左中右各有什么，**留出人物站的地面**：「画面下方 30% 是平整干净的浅色石板路面（后期人物站在上面走路，路面上不要放任何东西）」。中间要放 UI 的场景写「画面中央 70% 只有干净平整的墙面」。
- **角色动作表**：「横排 N 帧，等间距、等高、脚底对齐同一水平线，彼此之间留出明显空隙互不接触」，N ≤ 8；每帧写清朝向（「正侧面脸朝右」）和动作；同一角色的不同状态放在同一张表里（站着 / 背包 / 跪地 / 换装），保证是同一个人。手里不该有东西就写「手里不要画任何东西」。
- **循环动作的两帧要差得够大**：Codex 画的两帧常常几乎一样（走路、骑车、挥手），要写清每帧肢体的具体位置，比如「① 左脚在前、右手在前 ② 右脚在前、左手在前」「① 曲柄水平 ② 曲柄竖直」。
- **道具表**：「横排 N 个独立道具，彼此留出明显空隙互不接触、大小相近」。
- **同场景变体**（门关/门开、暗/亮）：先出 A，再以 A 为参考图：「严格照附图重画同一个场景（构图、所有物件的位置和像素块大小完全不变），唯一的变化：……」。
- **禁止**：画书（书一律 `pk cover`）、文字和招牌字、真实名人的长相、品牌 logo。

## 实测过的提示词（照抄改内容）

场景（`{BG}` 开头）：
- 小镇：`场景：温暖午后的小镇街道。两侧是各色小店铺（面包店、书店、杂货店，招牌空白），中景有路灯和行道树，远处是蓝天白云；画面下方 30% 是平整干净的浅色石板路面（后期人物站在上面走路，路面上不要放任何东西）。明亮温暖、生活感。`
- 卧室：`场景：夜晚昏暗压抑的卧室内景。左侧一张单人床、被子凌乱；后墙中间一扇窗户，窗帘紧紧拉上，只从缝里透出一线光；右侧墙上一扇关着的木门；床边小书桌上一盏台灯发出唯一的暖黄光；地上散落几件衣服和外卖盒。整体蓝灰暗调。画面中下部的地板区域要平整空旷（后期人物坐在这里）。`
- 地牢：`场景：地牢里一条长长的石砖走廊，横版侧视。深灰蓝色石砖墙，墙上隔一段挂一支燃烧的火把（暖橙色光），远处有拱门和铁栅栏，墙角有青苔和蛛网；画面下方 30% 是平整的石板地面，地面要平整空旷（后期会在上面放陷阱和人物）。神秘、略危险但不恐怖。`
- 城市：`16-bit 像素画横版游戏场景背景（SFC 时代侧视叙事游戏风格，16:9 宽画幅，大像素块，无抗锯齿，和附图同一款游戏的画风）：黄昏时分的城市街道。画面左侧是一个老式的小加油站……右侧是一栋高耸的蓝色玻璃写字楼……画面下方四分之一是一条平整干净的浅灰色人行道，横贯整个画面（角色会站在上面），人行道上空无一物。画面里不要有任何人物、不要有车、不要有文字和招牌字。`

角色表（`{STYLE} {GREEN}` 开头，参考 `hero.png`）：
- `同一个角色（就是附图里这个深棕短发、深蓝连帽外套的年轻人）的动作表：横排 6 帧，等间距、等高、脚底对齐同一水平线：① 正侧面脸朝右走路、低头看着手里的手机（左脚在前） ② 同①但右脚在前 ③ 正侧面脸朝右蹲在地上，双手端着一个圆形淘金盘向前伸 ④ 同③但淘金盘向另一边倾斜 ⑤ 正侧面脸朝右走路，右手举着一个放大镜在眼前往前看（左脚在前） ⑥ 同⑤但右脚在前。横版构图。`
- `两个新角色的动作表：横排 4 帧……：① 一位瘦小的白发老爷爷，戴蓝色鸭舌帽、穿洗旧的蓝色工装连体裤，正侧面脸朝右站着，双手握着一把扫帚；② 同一位老爷爷……背上背着一个鼓鼓的棕色旧背包，开心地笑；③ 一位三十多岁的精英男士，油头、笔挺的深灰色西装、红领带……正侧面脸朝左站着，下巴微抬很得意；④ 同一位西装男士，跪坐在地上双手抱头、领带歪了、非常沮丧。`
- 路人表：`横排 10 个不同的路人角色精灵，正面站立双手自然下垂，等高、脚底对齐同一水平线，彼此之间留出明显空隙互不接触：① 系围裙的妈妈 ② …`

动物/道具（`{MAGENTA}` 结尾）：
- `16-bit 像素画动物精灵，和附图同一款游戏的画风（大像素块、1 像素深色描边、无抗锯齿、Q 版比例）：一匹棕色小马，鬃毛深棕，横排 2 帧、等高、四蹄对齐同一水平线：① 正侧面、脸朝右站立 ② 同一匹马站在原地，但脖子和头扭向左后方、背过脸去（表示拒绝喝水），表情倔强。`
- `16-bit 像素画游戏道具：一辆鲜红色的豪华跑车，正侧面、车头朝右，低矮流线型车身……车子横向占画面大部分。`

## 像素化参数（`pk px <目录> <名字> …`）

| 素材 | 参数 |
|---|---|
| 背景 320×180 | `--no-key --width 320 --colors 40` |
| 主角/角色动作表（绿幕） | `--height 38 --colors 20–24`（新角色第一次不带 `--palette`，会输出 `名字.pal.png`） |
| 同一角色的追加动作 | 再加 `--palette web/assets/<角色>.pal.png`，颜色和之前一致 |
| 路人表 | `--height 38 --colors 28` |
| 道具表（洋红幕） | `--key magenta --height 18–20 --colors 24–28` |
| 单个道具 | `--single --key magenta --height <目标高>`（跑车 `--height 24`，卷轴 `--width 22`） |
| 动物 | `--frames 2 --key magenta --height 35` |

**切帧**：默认按列空隙自动切，Codex 画的表间距常常不均匀，自动切最稳。只有角色彼此挨着、自动切不开（帧数比预期少）时才加 `--frames N`——它按等分线附近找空隙，间距不均时会把一个东西劈成两帧、或把两个并成一帧，还会带大块空白。切错就换参数或让 Codex 重画。`--height` 是表里最高那个角色的真像素高度，38 = 和库里主角一样大。每次看 `gen/<名字>_px.png` 预览。
