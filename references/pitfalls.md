# 踩过的坑（出问题先查这里）

## 画面

- **整片白屏 / stills 报 “页面没能启动”**：多半是 ep.js 语法错，或在 ep.js 里重复 `const` 声明了引擎已有的名字（`darken`、`spr`、`fitCam`、`carryHero`、`carryAnchor`、`KW`、`M` 在骨架里已定义……）。看报错里的 PAGE ERRORS。
- **某个东西没画出来、也不报错**：`SP('名字')` 拿到 undefined 时大部分绘制函数会静默跳过。确认 `web/assets/名字.json` 存在、已登记（`pk sync <目录>`；`px`/`cover`/`stills`/`render` 都会自动登记）。
- **pkMarks 找不到锚句**：文稿里要有含《书名》的句子和「第一关：」开头的句子（见 script-writing.md）。
- **驼背帧方向反了**：`ck_hero` 第 2/3 帧原图朝左，朝右走要 `flip=true`。用 `carryHero` 就不用管。
- **背的东西和人重叠、堆在脑后**：违反硬规则，用 `carryHero`（多 → 驼背背架，少 → 小背包）。
- **云很假**：程序画的圆形云已从引擎删除，只用 `driftClouds`（像素云精灵），夜景/阴天用 `cloudF(CLOUD.warm, CLOUD.dark, k)` 调色。
- **像素字变成灰色糊块**：缺字回退到系统字体。模板用的 Fusion Pixel 12px 已补全常用字；别换回 Ark 像素字体（缺「读钱感经鉴」等 44 字）。生僻字仍可能缺，换个说法。
- **富人画成村民**：身份要对，富豪用西装角色、一群富人用剪影。
- **画面静止被 qa 判不合格**：长句子上只放一张卡片最容易静止。加 `camKeys` 推拉、次要动画（光晕呼吸、金币、角色换帧），或把句子拆短。
- **随机闪烁 / 每次渲染不一样**：用了 `Math.random()` 或跨帧状态。一律 `rnd(种子)`，画面只由 t 决定。

## 素材

- **Codex 卡住不动**：`codex exec` 必须 stdin 接 /dev/null（gen.py 已处理）；参考图 `-i` 后面要用 `--` 再写提示词（已处理）。
- **Codex 出的是「高清假像素」，缩小后碎**：提示词要带 `{STYLE}` 或 `{BG}`（强调整张图等于一张极小的像素图被放大）。
- **绿幕没抠干净 / 角色身上有绿**：角色本身含绿色就改洋红幕 `{MAGENTA}` + `--key magenta`。
- **出现黑底或光晕**：提示词里已带「不要黑色背景、不要光晕」；还是出了就拿失败图当参考重画，或换一张。
- **切帧切错**（一双鞋被劈成两帧、两个道具并成一帧、帧里一大块空白）：去掉 `--frames N` 让它按空隙自动切；还不行就让 Codex 重画并要求「彼此留出明显空隙互不接触」。
- **同一个人前后颜色不一样**：追加动作用 `--palette <角色>.pal.png`。

## 封面

- **书名对不上**：大陆译名可能不同（《Atomic Habits》→《掌控习惯》，台版《原子習慣》）。`cover` 已顺着「其他版本」列出全部版本；用大陆版封面时旁白交代译名，`book.name` 写封面上的书名。候选里没有想要的版本就用其他译名再搜一次，或 `--id`。
- **豆瓣打不开（要验证/限流）**：等一会儿重试，或让用户给封面图 `pk cover <目录> 书名 --image 封面.jpg`。
- **像素封面书名糊**：`--width 132`、`--colors 24`，或 `--lock white/dark` 只锁一种。
- **白底/浅色封面被洗白**（浅色图案锁成白）：`--lock dark --colors 24`。
- **想同时亮两个版本**（台版 + 大陆版）：第二个用 `--name book_tw`，ep.js 里 `SP('book_tw')`。

## 配音

- **edge-tts 报错 / 超时**：它要联网（微软在线语音），已自动重试 4 次；网络不好就再跑一次 `pk voice`，已配好的句子会跳过。
- **某个字读错**：在文稿里换同音字或换说法（比如「行长」容易读成 xíng），只重配改动的句子。

## 渲染

- **qa 报音画差 > 0.1s**：旧版拼接会少几帧；现在 render 每段多渲几帧再按音频长度裁齐（实测差 0.05s）。仍然不过就看 `out/parts/*.log`。
- **渲染很慢**：`--jobs` 设成 CPU 核数的一半左右；别同时跑两个 render。前 1–2 分钟的「预计还要」不准（各段起步慢），过了 8% 才给估算。
- **分享版编码**：Mac 用 `hevc_videotoolbox`（HEVC 8Mbps）；其他系统自动退回 libx264 CRF 21。
